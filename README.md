# Student Record Management System in C

## About
A beginner-friendly C programming project to manage student records using a menu-driven program.

## Planned Features
- Add student records
- Display all student records
- Search students by ID
- Save records to a file
- Load saved records from a file

## Technologies Used
- C Programming
- GCC Compiler
- File Handling
- Structures and Functions

## Learning Objectives
- Practice structures and arrays in C
- Understand functions and menu-driven programming
- Learn file handling in C
- Organize a project using GitHub
